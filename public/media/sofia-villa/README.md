# Material de Sofía Villa

- `photos/`: fotos de portada, galería y miniaturas.
- `videos/`: videos y teasers.

Nombres recomendados:
- `photos/hero.webp`
- `photos/gallery-01.webp`
- `photos/teaser-01-poster.webp`
- `videos/teaser-01.mp4`

Usá nombres en minúsculas, sin espacios ni tildes. Para web, preferir WebP para fotos y MP4 (H.264) para video.
